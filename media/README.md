# Media

Evidence for judges: prototype photos, diagrams, demo video links, screenshots of the dashboard.

| Subfolder (create when used) | Content |
|---|---|
| `photos/` | Robot and test setup, JPG under 1 MB each |
| `diagrams/` | Exported architecture and wiring diagrams (PNG or SVG) |
| `screenshots/` | Dashboard screenshots with the date and commit |

Videos do not go in Git: upload them elsewhere and list the links below.
