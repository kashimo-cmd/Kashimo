# Code of conduct

This project is a student engineering team project. We expect:
- Respectful, professional communication in issues, pull requests and reviews.
- Honest reporting: never claim a test passed or a result was measured if it was not.
- Review comments about the work, not the person.
- Safety first: no unsafe test practices near live electrical equipment.

Harassment or discrimination is not accepted. Report problems to the repository owner (@kashimo-cmd) or through a private GitHub security advisory. The owner may remove comments, close pull requests or block contributors who break these rules.
