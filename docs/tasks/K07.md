# K07 Head and rod

- Out: `pi/controller/head.py`, `pi/controller/rod.py`, `tests/test_head.py`, `tests/test_rod.py`.
- Head: held keys integrate 40 deg/s (2 deg per 50 ms step), clamp 0-180, pose holds on release. HOME goes to REST at 60 deg/s. Keys and HOME count only when the rod is UPRIGHT; a key press cancels a HOME. `goto(target, rate)` is the one move that runs whatever the rod does (boot and rod use it). Boot: the head is assumed in FOLD_POSE and goes to REST at 30 deg/s. Servo writes only when an angle changes.
- Rod: FOLDED, LIFTING, UPRIGHT, FOLDING, FOLDED at 30 deg/s (90 deg = 3 s). Lifting: fold servo up while the head goes to REST, UPRIGHT when both arrived. Folding: head to FOLD_POSE first, the servo moves down only after the head arrived. `request(robot_moving)` returns a refusal text or None: refused while the robot moves (`Drive.moving`, "stop first") and while the rod is already moving.
- Timeout: 5 s with no arrival (clock starts when the servo starts) stops the servo and `pop_alert()` returns "LIFTING" or "FOLDING" once (controller sends EVENT ALERT_ROD). The state stays LIFTING/FOLDING, so Drive keeps refusing. The next R, when stopped, sends the rod back the other way.
- Controller order each tick: `head.step(pan, tilt, rod.state)` then `rod.step()`; pass `rod.state` to `Drive.step(rod=...)` and `drive.moving` to `rod.request()`.
- Config (all optional): `head: {rate, home_rate, rest, fold_pose}` and `rod: {folded_deg, upright_deg, rate, timeout_s}`.
- Tests: one per transition, head-before-fold order, stopped-only, timeout (slow servo and head that never arrives), Drive interplay. Fake HW only. NOT RUN on the Pi.
- Not done (CHECK ON PI): `FOLD_POSE` is a placeholder equal to REST (90, 90), so the head will not tilt out of the way before folding until it is measured. Fold servo angles 0 (folded) and 90 (upright) are placeholders; the direction depends on how the servo is mounted. Rod `timeout_s` cannot fire from real hardware trouble: with no servo feedback it only catches a head that never arrives or a too-slow rate.
