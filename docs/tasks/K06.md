# K06 Drive

- Out: `pi/controller/drive.py`, `tests/test_drive.py`.
- Done: `mix(fwd, turn)` (forward = equal tracks, forward+turn = curve with inner track at 40 %, turn alone = pivot), `Drive.step()` with 0.3 s ramp, `drive.pwm_at_speed` scaling, STOP latch (`stop()` / `release()`) and the interlocks of table 5.4 that belong to drive. Refusal priority: latch, IMU calibrating, rod moving, obstacle. `step()` returns the refusal text for the dashboard, or `None`.
- Interlocks: front under 30 cm refuses forward only (S, Q, D work, a moving robot stops at once); latch refuses all drive; rod LIFTING/FOLDING refuses drive; IMU CALIBRATING refuses drive; `moving` flag lets the rod answer "stop first". `pop_obstacle_alert()` fires once per approach (re-arms above 40 cm).
- Hardware order: enable goes high before the first non-zero PWM, PWM 0 before enable low; any motor error leaves enable low and re-raises. `sensors.set_direction()` gets the applied direction (K05).
- Tests: 32 in `tests/test_drive.py` (one per interlock row, ramp, hardware order, config). Run on PC with fake HW only.
- Not done: `drive.pwm_at_speed` is a placeholder (0.6) until `calib_encoders` (K16) measures it. No `check_interlocks()` function: the check is inside `step()`. NOT RUN on the Pi.
