### K04 · Hardware layer
- **Did:** One `HW` class hides every motor, sensor, servo, LED and IMU call behind `HW_MODE=mock|pi`, so K05-K09 run on a PC. Mock mode records commands and takes fake inputs from `hw.sim`; Pi mode uses gpiozero + lgpio with the pins of 4.4.
- **Files:** `pi/controller/hw.py`, `tests/test_hw.py`
- **Run:** [PC] `set HW_MODE=mock` then `python -m pytest tests/test_hw.py`. Pi mode only runs on the Pi (not wired yet).
- **Tested:** [PC] pytest 195 passed (15 new in `test_hw.py`, Pi mode checked against fake gpiozero/smbus2 modules). NOT RUN on the Pi: real pins, PWM, HC-SR04 timing, encoders, MPU6050, servos, `iw`.
- **Status:** DONE · **Open:** servo PWM on Pi 5 is software PWM through lgpio, hardware PWM on GPIO 12/13 and fold on 19 to check; `pulse()` blocks up to 30 ms (K05 should call it in a thread or executor); `FOLD_POSE` still unmeasured.
