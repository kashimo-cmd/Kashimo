# Results

Every measured result lives here, one file per test run: `T<id>_<YYYY-MM-DD>.md`, made from [TEMPLATE_TEST_REPORT.md](TEMPLATE_TEST_REPORT.md). Small raw data (CSV, a few photos) goes next to it. Big files (videos) stay outside Git and are linked.
Add a line to [RESULTS.md](RESULTS.md) in the same pull request.
Test definitions: [docs/TESTING.md](../docs/TESTING.md), [docs/design.md](../docs/design.md) section 9.
Rule: no number in the README, report or slides unless it comes from a file here.
